# Implementation Plans

This directory contains task breakdowns for approved designs.

## Convention

Each plan is a numbered markdown file:

```
task-001-user-auth.md
task-002-order-api.md
```

## Task Template

```markdown
# Task N: Task Name

## Description

What to implement.

## Files

- **New:** `src/features/x/y.ts`
- **Modify:** `src/core/z.ts`

## Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2

## Dependencies

- Blocked by: Task N-1
- Blocks: Task N+1
```
